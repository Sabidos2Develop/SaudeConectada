# SaudeConectada
O projeto Saúde Conectada tem como finalidade desenvolver uma aplicação web ou móvel para auxiliar no acompanhamento preventivo de saúde da população, permitindo que unidades de saúde acompanhem informações provenientes de medições realizadas fora do ambiente clínico, através de dispositivos IoT vestíveis com SmartBands, que informam estas medições.   
A proposta está inserida no contexto de cidades inteligentes, utilizando dispositivos IoT, armazenamento de dados e Inteligência Artificial para transformar medições de saúde em informações organizadas e recomendações que possam auxiliar os profissionais responsáveis pelo acompanhamento dos pacientes Através de um Painel que gere Gráficos e dashboards além de alertas programados para avisar de pacientes em  situações preocupantes.   
O sistema deverá apoiar o trabalho das unidades de saúde na organização dos dados, identificação de alterações que mereçam atenção e acompanhamento de grupos vulneráveis, sem substituir a avaliação de profissionais de saúde.
