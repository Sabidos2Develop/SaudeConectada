# Backend — API REST

## Base confirmada

- PHP 8
- API REST
- MariaDB (persistência será desenvolvida no Incremento 2)

## Estado atual

Este diretório é o ponto de partida da camada backend. A estrutura interna, framework e bibliotecas ainda precisam ser aprovados. Não adicionar dependências de framework antes dessa decisão.

## Incremento 1

O primeiro fluxo a ser desenvolvido é o recebimento e a validação de telemetria de um dispositivo/simulador. O contrato de entrada e o protocolo precisam respeitar as decisões documentadas em `docs/decisions/`.

## Configuração
