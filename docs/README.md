## Fonte de requisitos

A especificação-base consolidada do projeto deve ser mantida como documento de referência versionado neste repositório. Até sua inclusão, a equipe deve consultar o arquivo **SAUDE_CONECTADA_DOCUMENTACAO_BASE_IA.md** compartilhado no contexto do projeto.

## Convenções

- Diferenciar requisitos confirmados, propostas técnicas e decisões pendentes.
- Não transformar exemplos em regras clínicas ou requisitos não aprovados.
- Registrar mudanças em contratos, arquitetura, tecnologia e regras de negócio.
- Relacionar Issues e Pull Requests aos requisitos e critérios de aceite.
