# Testes

Organização planejada:

- `integration/`: testes do fluxo simulador → comunicação → API.
- `fixtures/`: mensagens de telemetria fictícias, válidas e inválidas.

Os testes devem cobrir aceitação e rejeição de mensagens, validação no servidor e falhas de comunicação. Registrar comandos executados, resultados e limitações. Não utilizar dados pessoais reais.
